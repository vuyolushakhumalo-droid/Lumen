Lintel Motion Kit v0.1

Eight original motion patterns for single-file sites. No libraries. Every Lintel site gets this kit, inserted by the server where the model marks it — the CSS and JS on this page are generated from lib/motion-kit.js.

1 · Reveal on scroll

Add lk-reveal to any element. Fires once. Stagger with data-delay.

Each card fades and rises as it enters view

…120ms after the one before it

…so a row reads left to right

Scroll back up and down: it only plays once

2 · Hero drift + parallax

Settles from a slight zoom on load, drifts slowly forever, and moves at 0.6× scroll speed.

Far from home. Never far from the club.

Watch the photo: it settles from a zoom, then keeps drifting. Scroll and it lags behind the text.

3 · Tilt toward the cursor

Desktop only; touch devices get a static card.

Move the mouse across me — I lean toward it

Heavy feel: 300ms ease, snaps back on leave

Max 6° each way; static on touch screens

4 · Marquee

Write the items twice, with aria-hidden="true" on the repeats, so the loop is seamless. Pauses on hover.

5 · Count-up

Counts when it scrolls into view. Good for "since 1926", "1,200 members", "98% five-star". The real number stays in the markup; add data-plain for years.

Drag the handle. Uses a native range input, so it's accessible and works on touch.
